## 현재 구현과 출품 요건의 차이

현재 `pankeki/comfy_adapter.py`는 직접 로컬 8188 HTTP/WebSocket에 연결한다. 공식 SDK/Router 연동은 아직 없으므로 플랫폼 요건 충족으로 표시하지 않는다. [공식 SDK 문서](https://docs.comfy.org/development/api-development/sdks)는 `comfy-sdk`와 `comfy-api-proxy`를 이용한 로컬 실행을 지원한다. 로컬 proxy 기본 주소는 127.0.0.1:8189이고 기본 API key는 불필요하다. 이 경로의 설치·호환성·실제 생성 검증이 다음 기술 작업이다.

실제 생성·캐시·ROI·취소·revision 검증은 [results.ko.md](results.ko.md)에 있다. 부분 수정의 원본 밖 오차0과 편집 품질은 별도 판정이다. 작은 ROI의 경계·구도 문제 때문에 현재 ROI는 기본 off다. 완료 결과 재사용 시간을 새 이미지 추론 가속으로 소개하지 않는다.

현재 프로젝트 루트의 자체 앱 LICENSE, 공개 GitHub 저장소, 제출용 데모·소셜 게시물은 준비 완료 상태가 아니다. 의존성 라이선스 기록과 자체 앱의 OSS 공개 라이선스를 구분한다. 기존 로컬·무료 개발 제약은 유지한다. 계정·유료 사용·게시·제출은 실행하지 않았다.

## 확정된 제품 방향과 첫 구현 범위

사용자는 부모 채팅에서 **여러 분야의 오리지널 캐릭터 콘셉트 디자인 작업실**로 방향을 정하고, 활용 분야에 맞춰 조정하여 만들도록 요청했다. 게임 전용으로 한정하지 않는다. 제품 사진 스튜디오는 과거 미채택 검토 후보이며 현재 출품 방향이 아니다. 그 후보에 붙였던 예시 일정도 현재 개발 계획으로 사용하지 않는다.

첫 범위는 다음과 같다.

- 자유 창작·웹툰/웹소설·버튜버·마스코트·게임의 용도별 브리프와 예시.
- 동일 원본을 기준으로 만든 후보의 비교.
- 마스크 밖 원본을 보존하는 부분 편집.
- 선택 이력.
- 캐릭터 보드와 프로젝트 저장.

사용 흐름은 용도와 콘셉트 정리 → 후보 생성·비교 → 선택과 부분 수정 → 선택 이력 확인 → 캐릭터 보드·프로젝트 저장으로 연결한다. 이는 확정된 구현 범위이며, 각 기능의 완성·검증 여부는 별도로 기록한다.

새 포즈나 여러 시점에서의 캐릭터 일관성, 3D, 리깅, 최종 제작 에셋 자동 완성을 약속하지 않는다. 버튜버 용도는 콘셉트 디자인을 뜻하며 리깅된 방송용 모델 완성을 뜻하지 않는다. 게임 용도도 최종 엔진 투입용 에셋 완성을 뜻하지 않는다.

기존 Comfy 연동·캐시·revision·원본 보존 엔진과 실험 원자료는 재사용 가능한 기반으로 유지한다. 기존 찻주전자 생성이나 ROI 실험을 캐릭터 품질 검증으로 대체하지 않는다. 캐릭터 결과의 얼굴·손·경계·부분 수정 품질은 해당 입력과 출력으로 따로 확인해야 한다. 공식 SDK 연동과 대회 요건 충족은 여전히 별도 검증 항목이다.

## 공통 연구 기준과 병행 작업

사용자가 전달한 원 대화의 관심사는 차별점, 기술 설명, 사칙연산/행렬곱 변환, exact/approximate cache, quadtree/LOD/tile/실제 ROI였다. `CODEX-TASK.ko.md`와 `RESEARCH.ko.md`를 유지한다. 디스플레이·시선 렌더링 비유를 실제 diffusion 가속 근거로 쓰지 않고 CPU 계획과 GPU 실행, 원저작 코드와 자체 구현, 성공과 한계를 분리한다.

현재 부모 채팅이 `D:\Pankeki\web\` 전체 UI를 새 캐릭터 작업실 방향으로 구현 중이라고 전달했다. 개발 채팅은 이번 문서 반영에서 web 파일을 수정하지 않는다. 기존 엔진·모델·서버도 변경하거나 재시작하지 않는다. UI 구현 완료나 실제 화면 검증 완료로 간주하지 않으며, 새 UI와 엔진을 연결할 때 API·업로드 순서·취소·stale 결과 회귀 검사를 재사용한다.

장기적인 역할 제안은 부모 채팅=대회·제품 방향·디자인·통합 맥락, 개발 채팅=Comfy 연동·엔진·최적화·성능/품질이다. 이 전체 역할안의 최종 확정은 별도이며, 현재 web 편집 담당은 위 작업 지시를 따른다. 실제 공개·게시·제출은 별도 사용자 지시 또는 허락 없이 수행하지 않는다.
