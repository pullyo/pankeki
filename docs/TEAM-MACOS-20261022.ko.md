- UX: DESIGN.md와 디자인 기준·자산 제안. 프론트엔드 소스 변경은 프론트 담당과 총괄이 조율한다.
- 프론트엔드: web/src/redesign.js/CSS, app.js, studio.js, profiles.js와 관련 UI 테스트. character-* 모듈은 편집 담당과 계약을 맞춘다.
- 이미지 AI: pankeki/와 이미지 추론·모델 관련 스크립트/테스트. Mac 실행기는 출시 담당과 조율한다.
- 편집·모션: web/src/character-document.js, character-renderer.js, character-motion.js, character-export.js와 관련 단위 테스트. app.js 연동은 프론트 담당과 조율한다.

## 업무 운영

사용자는 총괄 채팅에 원하는 일을 전달할 수 있다. 총괄은 담당자에게 지시하고 결과·검증·한계를 수령·검토하여 필요 수정 지시와 보고를 한다. 담당자는 자기 채팅 완료 답변과 자기 보고서로 인계하며 다른 채팅에 메시지하거나 새 채팅/에이전트를 만들지 않는다.

UI 통일 스프린트의 완료 결과는 명부의 `sprint_history`·`previous_sprint`에 보존하고, 현재 `active_sprint`는 `human_vtuber_sprint`와 같은 사람형 콘텐츠 작업을 가리킨다. 기존 `human-vtuber-*` 이름·ready 표시·출력 파일 존재만으로 최종 수용하지 않는다. 최종 원화/리그·독립 QA·패키지 검수를 단계별로 구분한다. 상시 실행이나 자동 감시를 설정한 상태는 아니다. 필요 없는 병렬 작업이나 모델 추론을 실행하지 않는다. 인수인계 이후 제품 코드를 추가로 바꾸거나 외부에 게시하는 업무는 구체적인 사용자 요청과 배정 범위를 따른다.
