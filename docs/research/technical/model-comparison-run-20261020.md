# 이미지 모델 다운로드·실제 비교

2026-10-20 KST · 아지 총괄

최신 상태: 7개 가중치 검증과 12건의 실제 선별 실행·총괄 이미지 검토를 완료했다. [최종 결론](model-comparison-conclusion-20261020.ko.md)을 따른다. 아래는 최초 실행 계획이며 이전의 미다운로드/미실행 설명을 현재 상태로 읽지 않는다. 제품 SDK 통합·기본 모델 변경은 이 완료에 포함되지 않는다.

사용자가 여러 모델의 다운로드와 비교 실행을 승인했다. 기존 제품 코드를 바꾸는 작업과 분리한 로컬 실험이다. 아직 다운로드·추론 완료나 우승 모델을 판정하지 않았다.

## 대상과 역할

| 대상 | 실험 역할 |
| --- | --- |
| SDXL Base 1.0 | 기존 구현과 비교할 기준선. 복원된 폴더에는 가중치가 없어 다시 확보 필요 |
| FLUX.2 Klein 4B | 생성과 참고 이미지 편집 후보. 실제 지원되는 경량 구성부터 확인 |
| Qwen-Image-2.1 | 캐릭터 편집과 투명 소재 후보. 8GB 실행 경로·공개 배포 파일과 호환 런타임 확인 후 확보 |

공식 배포의 revision, 파일별 크기·해시, 라이선스, 필요한 encoder/VAE와 양자화를 기록한다. 실행 조건을 충족하지 못한 후보는 미실행·메모리 부족·미지원으로 구분하며 화질 실패로 평가하지 않는다. 추가 약관 동의나 유료 원격 GPU는 이번 실행에 포함하지 않는다.

- Pankeki 기술·모델 리서치: 실제 다운로드, 모델별 분리 환경, 추론 명령과 harness 인계.
- Pankeki 환경·회귀검증: 공통 입력·마스크, 평가 계획, 순차 실행과 결과 검수.
- 아지: 진행 조율, 산출물 확인, 모델 간 비교와 사용자 보고. 제품 구현 코드는 작성하지 않는다.

## 비교 방법

먼저 공통 생성 요청 1개와 같은 원본의 색·소재·표정 수정 3개를 작은 선별 실험으로 준비한다. 지원 기능과 실제 추론 시간에 따라 실행 수를 조정하고, 유망 후보만 추가 seed로 확인한다. 서로 다른 모델의 동일 seed 숫자를 같은 노이즈나 동일 조건으로 취급하지 않는다.

결과에는 모델·revision·양자화·해상도·steps·sampler·guidance·원본과 마스크 해시를 함께 남긴다. 모델별 권장 설정을 사용하고 차이를 공개한다. 생성 품질과 이미지 편집 결과는 별도로 비교한다.

평가 항목은 요청 충족, 얼굴·그림체 유지, 영역 경계, 원본 밖 RGB와 alpha 보존, 처음 적재/후속 실행 시간, 총 소요 시간, peak VRAM, 실패/OOM이다. 마스크 밖 합성 보존은 원시 모델 출력과 구분한다. 결과 이미지를 직접 검토하고 나란히 비교 보드를 제공한다.

## 자원과 완료 증거

착수 시 D: 여유 118.5GiB, C: 여유 12.8GiB였다. 대용량 다운로드·HF/pip 캐시·분리 환경·임시 파일은 D:에 둔다. 기존 백업이나 가중치를 삭제하지 않으며 중복 다운로드를 피한다. GPU는 한 번에 한 담당·한 모델만 사용한다. 앱의 기본 모델은 비교 결과를 검토하기 전 변경하지 않는다.

완료 증거는 `work/model-comparison-20261020/`의 다운로드 manifest, 실제 실행 로그·환경 기록, 원본·마스크·출력, 비교표·보드다. 진행 인계는 `docs/handoffs/model-comparison-downloads.md`와 `docs/handoffs/model-comparison-results.md`에 기록한다. 이 문서의 계획을 다운로드 또는 실험 완료로 해석하지 않는다.
