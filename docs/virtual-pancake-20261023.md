# 현재 팬케이크의 2D 버츄얼 프로젝트

2026-10-23. 사용자는 현재 팬케이크 캐릭터를 선택했고, 움직임은 기존 눈·입·호흡 조절/반복 재생으로 지정했다. 새 음성/웹캠 기능 추가가 아닌 캐릭터 프로젝트 제작이다.

원본은 `runtime/macos/ui-unification-20261023/ui-color-result.png`의 빨간 목도리·파란 손발·큰 눈 팬케이크다. 원본/현재 저장 프로젝트를 보존하고 새 `output/virtual-pancake-20261023/`에 별도 산출물을 둔다. 기존 제품 코드/로고/메뉴/데모는 바꾸지 않는다.

선택된 방식은 Pankeki의 기존 v2 문서와 자체 메시 렌더러다. 별도 Cubism SDK/모델 제작이나 음성/웹캠 추적은 선택한 범위에 필요하지 않다. 눈·입·호흡을 반복하는 기존 함수와 PNG/48프레임 ZIP 저장을 재사용한다.

원본은 한 장의 합성 이미지이므로 깨끗한 몸과 분리된 눈·입을 새로 준비해야 한다. built-in Imagegen으로 원본의 외형을 참고한 RGBA 소재를 준비하고 생성 프롬프트/출처를 보존한다. 픽셀 동일한 자동 분리가 아니라 새 움직임용 소재 제작이라는 점을 명시한다. 원본 위에 눈·입을 겹쳐 그리지 않는다.

제작 순서: 소재 준비/직접 확인 → 기존 문서 계약으로 부위·작은 메시·0/0.5/1 기준 형태·표정·반복 동작 작성 → 실제 파서와 pose 범위 확인 → 실제 앱에 파일 가져오기 → 슬라이더·재생/정지·저장/복원·출력 확인. 자연스럽지 않은 변형은 소재/키폼 범위에서 보정한다. 모든 삼각형의 양의 면적과 유효 리그 해시를 유지한다.

완료물은 Pankeki에서 다시 열 수 있는 v2 프로젝트, 소재, 실제 정지 미리보기와 동작 출력이다. 마이크/웹캠 추적, 물리, 고개 회전, Cubism 형식은 제공한 기능으로 표시하지 않는다. 실제 확인 결과와 표현 품질 한계는 최종 보고서에 나눈다.
