# SDXL Mac 연결

사용자가 SDXL 1.0 Base 설치와 Mac에서의 실제 이미지 생성·부분 수정을 요청했다. 기존 편집 전용 환경과 원본 자료를 보존하고 이 채팅에서 직접 진행한다.

- [x] 생성 전용 `.venv-macos`의 Mac 네이티브 의존성과 Metal 계산 확인.
- [x] SDXL만 공식 고정 revision에서 복구하고 SHA256 확인. SD Turbo는 설치하지 않음. 범위 다운로드의 한 조각에서 무결성 불일치를 찾아 공식 Hub/Xet 클라이언트로 복구했고 전체 SHA256이 일치함.
- [x] 기본 실행기는 생성 환경을 사용하고 `--editor-only`는 기존 독립 편집 환경을 사용하도록 연결. 실행 경로의 공백과 인자 전달 회귀 테스트.
- [x] ComfyUI와 앱을 127.0.0.1에서 실행. 기존 사용 중 포트의 다른 프로세스는 보존.
- [x] 실제 앱 HTTP 요청으로 SDXL 새 이미지와 마스크 부분 수정 PNG 생성. 수정 영역 변화, 영역 밖 RGB와 alpha 보존 확인. 생성 42.24초, 세 번의 수정 28.16~30.17초. 모든 수정에서 마스크 밖과 alpha 오차 0. 이미지도 직접 확인했으며 강도에 따른 형태·색상 한계를 안내에 기록함.
- [x] 기존 테스트와 설치 의존성 검사. 실행 안내·고정 Mac 패키지 목록·실제 생성 산출물·검증 결과 저장. Python 94 통과 / 20 플랫폼 제외, JavaScript 137 통과 / 1 skip / 1 TODO. pip check 통과.

Mac에서는 기존 direct ComfyUI 어댑터를 사용한다. Windows 프로세스 검증과 읽기 잠금은 사용하지 않는다. 정확 캐시 우회 상태를 유지하고 기존 Windows 성능 기록을 Mac 결과로 취급하지 않는다. 이번 작업은 SDXL만 대상으로 하며 디자인 개편·새 이미지 모델·Codex 대화 통합을 추가하지 않는다.
