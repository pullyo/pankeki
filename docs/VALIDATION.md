# 공개 스냅샷 검증

2026-10-19에 원본 개발 폴더와 분리된 공개용 복사본에서 실행했습니다.

| 검증 | 결과 |
| --- | --- |
| `python web/build.py` | 성공, 로고·프로필 포함, 외부 폰트·아이콘 다운로드 없이 빌드 |
| Python 핵심 검사 | 98개 실행, 97개 통과, Windows 권한 관련 1개 건너뜀 |
| 외부 워크플로 연결 검사 | 17개 통과 |
| SDK 브리지 검사 | 12개 통과 |
| Node 화면 상태·프로필 검사 | 55개 통과 |
| 공개 파일 점검 | 허용한 소스·문서·이미지만 포함. 자격 증명 패턴·개인 경로·비공개 채팅 ID 검사에서 검출 없음 |

검사는 기존 개발용 Python/Node 환경을 사용했습니다. 새 PC 설치 시험, 새 GPU 생성 시험, 이미지 품질 승인, 인터넷 공개 서비스 보안 검토를 의미하지 않습니다. `web/index.html`은 빌드해 확인했으며 재생성 가능한 산출물이라 Git에는 포함하지 않습니다.
