## 남은 문제

**대화 모델은 아직 미연결입니다.** 입력 근처에 이를 표시하고 보내기를 disabled로 두었습니다. 대화 예시는 입력 초안만 채우며 AI 응답을 꾸며내지 않습니다. 실제 이미지 생성은 상세설정의 기존 경로로 가능합니다. 기능 담당이 `chat-generation-contract.md`의 어댑터를 연결한 뒤 실제 대화→생성/수정 흐름을 추가 검증해야 합니다.

현재 스크린샷의 캐릭터 이미지는 기존 SD Turbo 시험 결과입니다. 이미지 모델 품질 개선이나 시각 디자인 최종 승인을 이 인계로 주장하지 않습니다. 총괄의 실제 화면 검수가 남았습니다.
