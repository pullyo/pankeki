# 쉬운 캐릭터 생성과 수정의 첫 사용자 흐름 검토

2026-10-20 KST · 제품 기획 → 아지 총괄 · 기존 기획·검증 인계만 재사용

**판단:** 첫 화면은 짧은 설명/내 그림 → 후보 비교 → 영역 수정 → 전후 비교·적용·되돌리기 → 저장·재개로 연결한다. 모델 설정은 보조로 두고, 대화가 미연결이어도 직접 도구로 시작할 수 있어야 한다. 아래의 ‘기반’은 기존 검증 인계 기준이며 현재 모델 비교·통합의 완료 판정이 아니다.

| 첫 흐름 | 확인된 구현 기반 | 이번 기한에 추가할 필수 UX |
| --- | --- | --- |
| 짧은 설명 또는 내 그림 | 브리프·용도 예시·이미지 업로드 | 시작 동작과 다음 행동을 하나씩 안내. 짧은 한국어 입력의 해석과 생성 기본값은 별도 검증하며, 미연결 Codex가 해석했다고 표시하지 않음 |
| 후보 비교·기준 선택 | 1~2후보·2개 비교·선택 이력 | ‘보고 있는 후보’와 ‘수정 기준’을 구분. 기준 그림·이름을 다음 수정에서도 표시 |
| 원하는 영역 수정 | 수동 마스크·부분 생성·마스크 밖 원본 보존 | 대상·변경 내용·마스크를 확인한 뒤 실행. 직접 색 조절은 추가 구현이며 준비된 도구만 활성화 |
| 전후 비교·적용·되돌리기 | 부모 후보 기록·원본/자식 비교·이전 후보 열기 | 결과를 적용 전 후보로 두고 사용자가 기준 변경. 편집 실행 취소와 기준 복귀를 구분하는 상태·조작 추가 |
| 저장·재개 | v1의 내장 이미지·브리프·후보·선택 이력과 자동 저장 | 마스크·부위·편집 설정용 새 형식과 v1 가져오기 검증. undo 이력까지 재개할지는 범위 확정 필요 |

**이번 기한의 필수:** 현재 단계·원본·처리 상태, 실패/취소와 다음 행동, 입력 보존, 실제 적용 여부, 저장 성공/실패를 일관되게 표시한다. 생성·수정은 명시 실행하고 늦은 결과가 다른 원본을 덮지 않게 한다. 빈 마스크 복사·캐시 재사용도 구분한다. **마스크 밖 픽셀 보존은 마스크 안 얼굴·머리·스타일의 동일성 보장이 아니다.** 재질·색 지시 충족은 별도로 확인한다.

**후속:** 자동 영역 인식·자동 파츠 분리/리깅, 범용 포즈·얼굴 추적, PSD·Cubism 전용 출력. 재사용 마스크·완전한 편집 저장·undo는 현재 미구현이지만 전체 제출 계획의 개발 대상이므로 후속으로 임의 이관하지 않는다. Codex·제한된 부위/변형/출력도 제출 계획의 필수 개발·검증 항목이며 이 메모로 제외하지 않는다.

**총괄이 확정할 최소 결정**

1. **적용·되돌리기의 단위:** 비교/열기는 기준 확정과 분리하고, 적용은 원본을 덮지 않는 기준 변경으로 정의한다. ‘이전 기준으로 복귀’와 색·마스크·부위 조작의 undo 범위·저장 여부를 공통 명령 계약에 명시한다.
2. **재개의 완료 기준:** 전체 계획의 v2와 Codex 범위서의 ‘v1 유지’를 조정한다. v1 가져오기 보존인지 저장 형식 유지인지 확정하고, 마스크·설정·부위·리그·선택·undo 각각의 복원 범위를 고정한다. 후보 request 보관을 현재 설정 복원으로 간주하지 않는다.
3. **첫 수정의 분기:** 단순 색 조절과 재질 부분 생성의 진입을 구분하고, 선택한 모델의 실제 앱 경로·기본값이 준비된 뒤 시연에 연결한다. 모델 비교 결과를 기다리는 동안 상태·저장 계약은 독립 확정할 수 있다.

검수는 같은 설명/내 그림에서 기준 선택→장갑색 수정→전후 확인·적용·복귀→저장 후 재개를 수행한다. 대기·실패·재시도를 포함한 시간·직접 조작·도움 요청과 지시 충족/픽셀 보존/복원 상태를 각각 기록한다. 아직 편리함의 측정 결과는 없다.
