# Pankeki 메인 워드마크 독립 시각 검토

검토일: 2026-10-19 (한국시간). 실제 Chrome 155.0.8059.82, 1440px viewport, deviceScaleFactor 1로 원본 PNG를 CSS 크기만 변경해 표시했다.

## 판정

새 생성본은 사용자 선호 참고 이미지의 따뜻한 일러스트형 브랜드 방향을 충실히 따른다. **흰 배경과 #252a23 배경의 실제 브라우저 표시에서 220px·280px 헤더 크기, 700px 확대 모두 사용 가능한 시각 품질**이다. 이 판정은 독립 검토 결과이며 사용자 최종 승인을 대신하지 않는다.

팬케이크 3장의 폭신한 두께, 구운 윗면, 입체적인 연노랑 버터, 호박색 시럽, 짙은 갈색과 크림색의 풍성한 글자가 분명하다. 이전 단순 타원 아이콘과 달리 팬케이크로 즉시 읽힌다. 철자는 **Pankeki**로 정확하게 읽힌다. 참고 이미지처럼 i 위의 하트도 유지되어 있다.

전체 외곽의 크림색 띠와 가는 따뜻한 주황색 경계는 참고 이미지의 스티커형 테두리에 해당하며, 흰 배경 제거 실패로 남은 넓은 흰 사각형이 아니다. 어두운 배경에서도 시럽/크림색 글자/갈색 테두리가 안정적으로 분리된다.

## 확대 미리보기의 색 점과 실제 표시

직접 원본을 `view_image`로 열면 노란 외곽 점, 붉은 점과 하단 붉은 선이 두드러져 보였다. 그러나 원본을 그대로 표시한 Chrome 캡처에서는 220px·280px뿐 아니라 700px 확대에서도 이러한 색 잔여물이 육안으로 보이지 않았다. 이 브라우저 증거를 우선하면 **강한 색 번짐은 실제 헤더 표시 결함으로 재현되지 않는다.**

PNG를 읽기 전용으로 분석한 결과 완전히 불투명하지 않은 미세 알파 흔적은 실제로 존재한다. 따라서 원본이 수학적으로 완전히 정리된 알파 마스크라고 말하지 않는다.

- 2172×724, 8비트 RGBA PNG.
- 알파 0: 725,230픽셀. 알파 1–15: 14,880픽셀. 알파 16–127: 3,785픽셀. 알파 128–254: 826,644픽셀. 알파 255: 1,989픽셀.
- 알파 ≥1 기준 본체 외에 297개 작은 분리 성분이 있고, 합계 877픽셀이다. 가장 큰 분리 성분은 133픽셀이며 최대 알파 1/255다.
- 알파 ≥16(약 6.3% 불투명도)에서는 이미지 전체가 단 하나의 연결 성분이며 분리된 점이 없다. 알파 ≥128에서도 단 하나의 연결 성분이다.
- 즉, 미리보기에 과장되어 보인 고립 흔적은 매우 낮은 알파 영역에 있으며, 이번 실제 브라우저 확인 크기에서 눈에 띄지 않는다. 미리보기 렌더러의 정확한 내부 원인은 조사하지 않았으므로 확정하지 않는다.

브라우저 화면 품질을 이유로 다시 기본 조형을 바꿀 필요는 발견하지 못했다. 원본의 낮은 알파 미세 흔적까지 제거해야 하는 고해상도 출판·인쇄용 납품은 별도 품질 기준으로 다뤄야 한다. 이 작업에서는 이미지 편집이나 재인코딩을 수행하지 않았다.

## 참고 충실도 및 적용 판단

- 구성, 색, 글자 분위기, 시럽, 버터, 하트가 매우 가까우며 선호 참고 이미지의 장점을 유지한다. 독립적으로 전혀 다른 로고를 만든 결과로 설명하면 안 된다.
- 참고 파일은 2032×774(약 2.63:1), 새 생성본은 2172×724(3:1)로 가로형 비율과 여백이 더 압축되어 있다. 글자는 약간 더 통통하고 내부 디테일이 조금 정리되었다.
- 280px 너비의 실제 높이는 약 93px, 220px 너비는 약 73px다. 이 크기에서는 읽힘이 좋다. 40px 높이의 매우 얇은 앱 헤더에 이 검토 결과를 그대로 일반화하지 말고 최종 배치 높이를 별도로 확인해야 한다.
- 이 메인 워드마크 전체를 32px·48px 정사각 아이콘으로 사용하는 것은 이번 검토 대상이 아니다. 아이콘은 같은 정체성에서 별도 파생하는 편이 적절하다.
