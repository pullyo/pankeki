# Codex 최소 텍스트 채팅 — 기한 범위·견적

2026-10-20 KST · 내부 완료 기한 **2026-10-30 KST** · 설계 검토용, 실제 기능 미구현

기준: [기존 제안서](codex-chat-proposal.md), [프론트 계약](warm-frontend-implementation.md). 기존 ChatGPT 인증과 프로세스 한정 제한 설정의 적용까지 확인했다. 실제 채팅 전송·모델 응답·통합 동작은 아직 검증하지 않았다.

**최소 범위:** 기존 Codex/ChatGPT 인증의 텍스트 채팅, 프로젝트별 별도 대화, 전송·취소·오류 표시, 구조화된 변경 제안 확인. 제안은 사용자가 확인한 뒤 기존 브리프 검증으로 적용하며, 이미지 작업은 기존 generate를 별도로 명시 호출한다. 이미지 입력·새 API 키·결제·대화 내보내기·리깅·추가 모델은 이번 채팅 범위에서 제외한다. 버전1 프로젝트 형식과 이미지 생성 경로를 유지한다.

| 순서 | 담당·산출물 | 통과 기준 / 실패 시 처리 |
| --- | --- | --- |
| 1 | 총괄: 압축 출품 범위서의 사용자 검토와 HTTP/세션 계약 확정 | 검토 전 코드·thread·turn 추가 없음. 총괄은 배정·검수만 맡는다. |
| 2 | 백엔드: **별도 소규모 도구 집합 검증 과제** | 승인된 범위 안에서 설치 버전의 실제 thread 도구 집합·설정 상속을 확인한다. 셸·파일 작업·외부 MCP 등 실행 도구가 제거됐는지 입증하기 전 원격 turn 금지. 실패하면 이유를 기록해 총괄이 보완/범위 제외를 결정하고, 제한을 풀거나 다른 과금 경로로 우회하지 않는다. |

| 5 | 환경·회귀 담당: 정상 사용자 실행 환경에서 최소 통합 검증 | 별도로 승인된 실제 텍스트 전송 1회, 프로젝트 2개 분리, 취소·오류 경로, 제안 확인 후 기존 작업 연결을 확인한다. 인증 만료·한도·네트워크 오류는 제어된 응답으로 재현하고 자동 재전송·추가 결제 없음. GPU 비교 9개는 반복하지 않는다. 실패 항목은 미완료로 표시한다. |
| 6 | 디자인 담당 빌드 → 검수 담당 재확인 → 총괄 통합 판정 | 최종 화면의 실제 연결/미연결 안내와 동작 증거를 확인한다. 기준 미달이면 채팅을 비활성화하고 제한을 명시하며 완료로 포장하지 않는다. |

**착수 차단 조건:** 1번 사용자 검토·계약 미확정, 2번 도구 제한 미입증, 정상 홈을 인식하는 브리지 실행 환경 미확보. 이때 독립적인 화면 작업은 진행할 수 있으나 채팅 생산 코드는 착수하지 않는다. 인증은 현재 기존 로그인으로 확인됐고, 만료 시에만 공식 로그인에 사용자 개입이 필요하다.

**견적(미측정 추정):** 1번 확정 후 2번 0.5작업일, 통과 후 백엔드 1~1.5일·프론트 0.5~1일, 통합 검증/수정/빌드 1일, 여유 1일로 **경과 4~5작업일**을 잡는다. 2번이 0.5일 안에 결론 나지 않으면 총괄에게 위험과 다음 선택을 즉시 보고하며, 반복 조사로 기한을 소진하지 않는다. 10월30일은 내부 완료 기준이며 외부 제출 기한과 구분한다.

**호환성 위험:** 실행기는 `0.163.0-alpha.10.2`. 최신 문서와 승인 정책 표기·제한 읽기 필드가 다르므로 로컬 생성 스키마와 이미 실측한 설정을 기준으로 고정한다. 전역 업데이트/설정 변경을 하지 않으며, API 불일치는 명시적 incompatible 상태로 중단한다. `mcp_servers={}`만으로 상속 설정이 제거되지 않는 점을 구현 인계에 포함한다.

**후속 인계:** 백엔드는 브리지/라우트/관련 테스트, 프론트는 chat UI·토큰·제안 확인, 환경·회귀는 독립 검증, 디자인은 최종 빌드를 맡는다. 각 담당은 실제 변경 파일·실행 결과·남은 한계를 기록한다. 이번 산출물은 이 문서뿐이며, 새 조사·코드·thread/turn·추론·다운로드는 하지 않았다.
