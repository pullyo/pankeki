# Pankeki 10월 30일 제출 준비 체크포인트

2026-10-20 KST 작성. 사용자 내부 완료기한은 **10월 30일**이다. 총괄의 **10월 28일 기능 동결 → 29~30일 검수·제출 준비**에 맞춘 실행안이며, 최종 출품 범위와 구현 계획의 승인을 뜻하지 않는다. 아래 시각은 모두 KST의 제안이다. 공식 제출창은 기획팀 10월 20일 [확인 기록](../product/contest-requirements-2026-10-20.ko.md) 기준 **10월 30일 09:00 PT = 10월 31일 01:00 KST**다. 내부 목표 제출 시각은 10월 30일 18:00으로 두어 7시간의 여유를 남긴다. 외부 마감을 작업 종료 목표로 미루지 않는다.

## 현재 기준선

| 항목 | 확보한 근거와 남은 조건 |
| --- | --- |
| 따뜻한 화면 | 7개 화면과 최종 HTML 통합 완료. 기존 Node **92/92**, 실제 Chrome **94/94** 기록을 재사용한다. 홈 썸네일 후속 검사 2/2, 상태 문구 정리 4/4도 별도 기록이다. [디자인 인계](../handoffs/warm-design-implementation.md), [프론트 인계](../handoffs/warm-frontend-implementation.md) |
| 브라우저 증거의 범위 | 검증 프리뷰 8192는 생성 API가 503이고 API 쓰기/생성은 0회였다. 이후 변경은 ‘Codex 대화 미연결’ 문구뿐이라는 검사 근거가 있다. 이 결과를 8190의 현재 SDK/GPU 성공으로 확대하지 않는다. |
| 실행 환경 | 앱·SDK venv 복원, SDK bridge 12/12 및 양쪽 `pip check` 통과로 예전 SDK 누락 오류는 해결됐다. 새 PC 설치 재현과 실제 GPU 경로는 별도다. [후속 QA](../handoffs/resume-qa-tooling.md)가 옛 [출시 준비표](2026-10-20-release-readiness.ko.md)의 환경 부재/SDK 5 error 기록보다 최신이다. |
| 모델 비교 | 사용자 승인으로 다운로드·비교 준비/실행 작업이 진행 중이다. 읽은 [QA 비교 인계](../handoffs/model-comparison-results.md)는 입력·평가 준비 완료, 신규 품질/시간 결과 미측정 상태다. [비교 계획](../research/technical/model-comparison-run-20261020.md)을 완료/승자 판정으로 취급하지 않는다. |
| 실제 Codex | 인증·프로세스 제한 설정 조사와 HTTP 계약 제안 단계. 실제 Pankeki 대화 연결은 **미구현**, send는 disabled다. [최신 제안](../handoffs/codex-chat-proposal.md)의 인증 확인과 실제 원격 대화 성공을 구분한다. |
| 부위·메시 | 부위 영속화/RGBA 파츠 편집/메시·리그·키폼·동작은 **미구현**. 현재 parts/motion은 준비 전 안내다. 계획 화면을 작동 결과처럼 시연하지 않는다. |

[공식 공고](https://comfy.org/open-source-higgsfield/)와 기존 기록의 [제출 폼](https://form.typeform.com/to/V1dSQrkS)·[신청 폼](https://form.typeform.com/to/Ayn9Cwfj)의 최신 조건은 위 일정에서 재확인한다. 이번 문서 작업은 외부 재조사나 폼 입력을 수행하지 않았다.

공개 repo/demo/social 링크는 10월 30일 12시까지 내용·접근 권한·교차 링크·영상 길이·허위 완료 표현을 검토할 수 있는 상태로 준비한다. 게시가 필요한 링크는 총괄이 승인/담당 범위를 정해 실행한다. 폼 필수 조건이 해결되지 않았거나, 후보가 설치·SDK·저장 필수 흐름을 재현하지 못하면 단순히 마감 직전까지 새 기능을 붙이지 않고 총괄이 범위/출품 여부를 결정한다. 접수 화면/메일은 실제 제출 후에만 완료 근거로 남긴다.
