# Pankeki 계획 대비 구현 누락 점검

2026-10-20 KST · 아지 총괄 · 코드와 기존 인계의 읽기 전용 대조

최신 결정: 사용자가 움직임 설계와 [실행계획](../superpowers/plans/2026-10-20-motion-first-implementation.md)을 승인했고 기존 작업팀이 실제 구현 중이다. 아래 표는 구현 착수 전 감사 시점 기준이며 현재 완료 표가 아니다. 진행 상태의 단일 추적은 [전체 기능 추적표](feature-delivery-tracker-20261020.ko.md)로 이어 간다. undo 이력의 실행 중 유지 범위는 설계 승인으로 확정됐고, 외형 조합/참고 조건 등 다른 정의 항목은 남아 있다.

사용자는 실제 2D 움직임부터 구현하고, 기존 계획에서 빠진 항목을 확인하도록 요청했다. 이 문서는 구현 완료 보고가 아니다. 현재 가장 큰 누락은 **부위·변형·동작·편집 저장을 잇는 실제 기능**이다. 해당 기능은 기획과 준비 화면에 있으나 생산 코드에는 없다. 총괄은 기획→담당 배정→실제 착수→독립 검증을 연결해 추적하지 못했고, 기능 설명에서 예정과 구현을 충분히 분리하지 못했다.

## 계획 사이에서 빠지거나 충돌한 정의

1. **저장 후 되돌리기:** 초기 구성안은 마스크와 이력의 복원을 말하지만 v2 계약은 undo를 런타임 전용으로 둔다. 저장되는 선택 기록, 편집 체크포인트, undo 스택을 구분해 범위를 확정해야 한다. 조용히 제외하지 않는다.
2. **외형 재사용:** 외형3안×표정3개 목표에 맞는 소재 변형안·리그 재바인딩 계약이 없다. 소재 교체 시 hash가 달라지는 기존 규칙과 조합 재사용의 연결을 정의해야 한다.
3. **움직일 실제 소재:** 합성 사각형 fixture 외에 정면 캐릭터의 분리된 눈·입·몸·가려진 배경과 사용 권한이 확인된 소재가 필요하다. 준비된 소재 가져오기와 단일 PNG 자동 분리는 다른 범위다.
4. **참고 이미지의 의미:** 현재 첨부는 수정 원본이다. 별도 참고 이미지를 모델이 읽어 스타일/정체성을 따르는 기능, Codex의 이미지 이해는 현재 구현된 것으로 약속할 수 없다.
5. **현재 편집 상태 복원:** 후보 request를 저장하는 것과 지금의 수정 기준·작업 중 마스크·도구 설정을 복원하는 것은 다르다. 저장 직전 미등록 마스크와 현재 원본 선택의 처리도 명시해야 한다.
6. **미연결 안내 정합성:** template의 상단은 Codex 미연결이지만 chatNotice에는 로컬 모델 문구가 남아 있다. 기능 연결 상태와 일치하도록 후속 UI 수정에 포함한다.

이전 기획의 수동 요구 판정과 추론 없이 경계만 재합성은 검토 제안이다. 현재 필수 개발 범위로 자동 승격하거나 완료로 처리하지 않는다. 채택 여부를 기록해 제안이 유실되지 않게 한다.

## 최신 우선순위와 완료 증거

사용자가 움직임부터 요청했으므로 **준비된 부위 → 실제 메시/키폼 → 눈·입·호흡 조절 → 재생/정지 → 저장·재개**를 먼저 잇는다. 모델 비교는 기존 승인과 단일 GPU 조건을 유지한다. Codex·색 조절·외형 조합 등 다른 미완료 항목은 목록에서 삭제하지 않는다.

움직임은 실제 앱에서 사용자 PNG 부위를 넣고 중간 형태를 조절하며 재생·정지한 증거, 같은 프로젝트 재개, 새 추론 요청 0회, 원본·알파 보존을 확인한 뒤에만 완료로 판정한다. 구체 설계는 [움직임 우선 설계](../superpowers/specs/2026-10-20-motion-first-design.md)를 따른다. 현재는 **승인 후 구현·통합 진행 중**이며 검증된 최신 상태는 기능 추적표를 따른다.

프론트엔드와 기능 담당의 독립 읽기 검토 두 건을 수집해 대조했다. 둘 다 코드·테스트·빌드·GPU 실행 없이 확인했다. 추가로 출력 패키징·실패/취소 처리, 재생값과 undo/저장값의 분리, 조합된 파라미터에서의 삼각형 검증, 서버 저장 API의 필요 여부를 설계에 명시해야 함을 확인했다. 이 사항은 움직임 설계 검토본에 반영했다.
