# Pankeki 주요 기능과 전체 화면 시안

2026년 10월 20일. 아래 7장은 한 앱의 제작 흐름을 보여주는 디자인 시안이다. 실제 앱에 적용하거나 기능을 새로 구현한 결과는 아니다.

| 화면 | 주요 기능 | 현재 상태 |
| --- | --- | --- |
| [1 프로젝트 홈](01-project-home.png) | 새 캐릭터 생성, 내 이미지에서 시작, 최근 프로젝트 열기 | 신규 화면 구성안 |
| [2 이미지 생성](02-image-generation.png) | 설정 입력, 모델·비율·후보 수 조절, 캐릭터 후보 생성 | 생성 코드·SDK 경로 구현. 현재 모델·GPU 실행 환경 복원 필요 |
| [3 후보 비교](03-candidate-comparison.png) | 후보 확대·비교, 생성 조건 확인, 선택한 후보에서 이어서 수정 | 기존 기능 기반 화면 개편안 |
| [4 부분 수정](04-mask-inpainting.png) | 브러시·지우개·마스크 불러오기, 수정 범위와 강도·경계 조절 | 기존 수동 마스크 수정 기반 화면 개편안. 현재 추론 환경 복원 필요 |
| [5 부위 편집](05-reusable-parts.png) | 이름 붙인 부위·마스크 저장, 보호·잠금, 색·위치·크기 조절, 투명 소재 관리 | 개발 예정 |
| [6 표정과 동작](06-expression-motion.png) | 메시·키폼·파라미터, 표정 프리셋, 시간 곡선과 반복 동작 | 개발 예정 |
| [7 저장과 출력](07-project-export.png) | 이미지·보드·프로젝트 저장, 표정 시트·부위 PNG·연속 프레임 출력 | 기본 저장 구현. 부위·동작 저장 형식과 확장 출력은 개발 예정 |

대화는 생성·편집의 공통 입력 경로로 기획했다. 실제 대화 모델은 미연결이다. 자동 부위 분리·리깅, 전신 포즈, 물리, 얼굴 추적, Cubism·PSD 연동, 동영상 출력은 후속 검토 범위다.

시안 안의 이미지·수치·후보·조절 결과는 조작 흐름을 설명하는 예시다. 이미지 안에 나타나는 개발 상태 문구보다 위 표가 현재 구현 상태의 기준이다.

화면은 내장 이미지 생성 도구로 만들었다. 생성 원본을 수정 없이 복사했고 7개 모두 원본과 SHA256이 같다. 사용한 프롬프트와 참고 파일은 [prompts.json](prompts.json)에 보존했다. 기능·데이터·검증의 상세 설계는 [공통 캐릭터 제작 기획안](../character-workflow-live2d-plan.ko.md)을 따른다.
