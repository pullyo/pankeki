## 수용 조건

1. U1–U8의 원래 현상별 실패 회귀/실측 기준을 유지하고 수정 후 재확인한다.
2. 1280×800·1440×900·1920×1080에서 홈/생성/디자인/비교/부위/동작/출력과 설정 모달을 확인한다. 준비 전과 제공된 데모 리그 준비 후 상태를 모두 확인한다.
3. 메뉴 11개의 순서·위치, 원본 로고, 일반 글자 대비 ≥4.5:1, 이미지 전체 표시와 후보 비교의 같은 배율, 유효한 준비 선택, 모달 Escape/닫기, 기존 이미지/프로젝트 저장을 확인한다.
4. 기본 JS 회귀와 영향을 받는 모션/UI 검사를 실행한다. 변경 파일 및 백엔드/로고/문서·렌더·출력 엔진 불변 해시를 기록한다. 이미지 모델 재추론은 레이아웃 수정에 불필요하다.
5. 실제 스크린샷은 fullPage:true로 수집하고 파일 픽셀 치수와 DOM viewport를 대조한다. 리사이즈 직후 중간 상태와 최종 상태, 기술 검사와 시각 수용, 미검증 범위를 구분한다.
