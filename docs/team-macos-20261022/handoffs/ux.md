## 역할과 보존 범위

설명 입력 → 실제 이미지 생성 → 확인·부분 수정·저장 흐름과 공통 시각·접근성 기준을 담당한다. 기존 로고, 11개 메뉴, 실제 생성·업로드·마스크·후보·프로젝트·모션·출력을 보존한다. 중앙 PC 채팅 작업 공간, 작은 조작부와 이미지의 시각적 비중을 유지한다. 후속 프론트 소스 변경은 총괄·프론트 담당과 조율한다.

## 이번에 직접 확인한 구현과 화면

- **현재 소스 정적 확인:** [redesign.css](</Volumes/Samsung 970 EVO Plus/V/restored-20261020/Pankeki/web/src/redesign.css:82>)의 색상 토큰, 216px 사이드바, 기본 최대 960px 대화열, 포커스 표시·동작 줄이기 규칙을 확인했다. [redesign.js](</Volumes/Samsung 970 EVO Plus/V/restored-20261020/Pankeki/web/src/redesign.js:124>)에는 가시 설명 입력 `pcPrompt`, 연결된 레이블, 7개 스타일의 선택 상태, 상태 알림·이미지별 보기/수정/저장 연결이 있다. 명명된 설정 dialog·ARIA 탭, 방향키/Home/End, Enter 제출·Shift+Enter 줄바꿈·한글 조합 중 제출 방어도 소스에서 확인했다. 실행 동작을 이번에 재현한 것은 아니다.
- **기존 최종 캡처 2개 육안 확인:** [final-1440.png](</Volumes/Samsung 970 EVO Plus/V/restored-20261020/Pankeki/runtime/macos/pc-chat-ui/final-1440.png>), [final-1920.png](</Volumes/Samsung 970 EVO Plus/V/restored-20261020/Pankeki/runtime/macos/pc-chat-ui/final-1920.png>)에서 기존 로고·11개 메뉴, 단일 대화열, 전체 결과 이미지와 인접한 크게 보기/부분 수정/저장, 선택 스타일과 사용자 설명을 확인했다. 두 장은 저장된 검증 화면이며 현재 실행 화면을 새로 캡처하지 않았다.

## 기존 검증 기록에서 인계한 결론

[review.md](</Volumes/Samsung 970 EVO Plus/V/restored-20261020/Pankeki/runtime/macos/pc-chat-ui/review.md>)에 따르면 이미지 하단·동작 가림, 설명/스타일 혼재, 모델·크기 설정 진입, 설정창 의미, 스타일 안내의 우선 문제 5개를 수정·재확인했다. 26/40은 **수정 전** 점수이며 최종 전체 점수는 없다. 선택 액션 대비 4.709:1과 주요 문자 표본의 4.5:1 초과는 기존 측정 결과이며 전체 앱 보장은 아니다.

같은 보고서는 실제 SDXL 생성, 설명·스타일의 새로고침 복원, 키보드 탭·본문 바로가기·Escape 포커스 복원, 세 데스크톱 크기의 넘침/이미지 동작 노출을 기록한다. 이는 기존 수행자의 검증이며 이번 온보딩에서 테스트·빌드·브라우저·추론·detector를 실행하지 않았다.

## 미확인·남은 문제

- 실제 VoiceOver 읽기와 고배율 확대의 전체 작업 흐름은 미검증이다. 기존 detector 경고는 숨은 이전 화면도 포함하므로 현재 결함 수나 해결 수로 환산하지 않는다. 홈·편집 등 다른 화면의 작은 글자·낮은 대비는 후속 확인 대상이다.
- 영어 설명 권장과 세부 모델 옵션의 학습 부담이 남는다. 실행 중 실제 취소, macOS 다운로드 파일 도착, 이번 UI 변경 후 새 마스크 추론도 해당 보고서의 검증 범위 밖이다. 관련 담당·QA와 확인 범위를 맞춰야 한다.
- 현재 서버 실행 상태나 최신 동작 성공을 이번 열람으로 확정할 수 없다. 과거 Windows 팀 문서·시각 콘셉트·모델 기록은 현재 구현·승인 근거로 사용하지 않는다.
