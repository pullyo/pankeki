## 역할과 현재 구현 — 이번에 소스로 확인

- **상태 소유권:** `web/src/app.js:764–784`의 `PankekiStudio`가 생성·취소·프로젝트와 구독 API를 제공한다. 요약은 동결된 작은 객체이며 구독 해제 함수를 반환한다. `web/src/studio.js:24–98`은 기존 핸들러로 화면·모드·포커스를 연결하고, `redesign.js`는 그 위에 채팅 표현을 구성한다. 기존 로고·11개 메뉴와 생성·마스크·후보·프로젝트·모션·출력은 보존 대상이다.
- **입력 경계:** `web/src/redesign.js:28–44,124–138,290–296,351–365`. 가시 `pcPrompt`의 입력을 숨은 원래 `prompt`에 전달하고 기존 `input` 이벤트를 발생시킨다. 제출 helper는 기존 스타일 suffix를 제거한 뒤 선택 스타일 하나를 덧붙여 `studio.generate()`를 호출한다. 편집창은 설명만 표시하며 포커스 중 덮어쓰지 않는다. Enter는 제출, Shift+Enter는 줄바꿈이며 조합 입력을 제외한다. 복원·가져오기는 저장된 suffix로 스타일을 맞춘다. `app.js:221–265,417–433`의 기존 브리프·요청 경계를 유지한다.
- **실제 후보 기록:** `redesign.js:46–51,145–187,290–296`은 `studio.exportProject()`의 `versions`를 순서대로 표현한다. 업로드는 참고 이미지로 구별하고 가짜 요청·응답을 추가하지 않는다. 후보 수 변화 때 추가하며 복원·가져오기·초기화는 강제 재구성한다. 확대·부분 수정은 기존 후보 버튼에 연결되고 저장 링크는 해당 이미지다. `selectionHistory`는 별도의 선택·편집 이력이다(`app.js:519–527`).
- **생성·취소·오류:** `app.js:308–315,467–506`은 요청·브리프·부모 후보를 비동기 작업 전에 확보하고, `serial`로 늦은 성공·이미지 읽기 결과를 차단한다. POST 응답 전 취소도 뒤늦게 받은 job에 취소를 요청한다. 이미 완료한 후보는 후속 실패에도 남긴다. 취소는 GPU 연산의 즉시 종료를 보장하지 않는다. `redesign.js:313–327,351–359`는 busy 중 제출을 막고 취소를 노출하며 오류를 `role=alert`로 유지한다. 일반 완료·취소 안내는 busy 종료 후 composer에서 비워지고 원래 status/badge에 남는다.
- **복원 계약:** `app.js:623–729`는 v1 이미지 전부를 decode하고 revision/epoch를 확인한 뒤 교체한다. 늦은 import·자동 복원이 새 입력을 덮지 않도록 방어하며 잘못된 파일은 기존 작업을 유지한다. 브리프·후보·선택 이력을 IndexedDB에 저장하지만 편집 마스크는 복원하지 않으므로 다시 칠해야 한다. v2는 별도 모션 컨트롤러로 전달한다. 원본·마스크 제출과 후보 편집은 기존 경로를 따른다(`app.js:338–391,428–431,523–527`).
