Character studio guide

  1. Enter intended use, description, and appearance.

    You can start with Use example. Intended use changes design instructions, not the generation model.

  2. Generate and compare candidates.

    Explore 1–2 candidates at a time. Use the candidate controls on the right to view, select for comparison, or continue editing.

  3. Edit the areas you choose.

    Import a source image and paint the edit area with the brush. You can also import a mask file using the keyboard.

  4. Save your project and board.

    Project files include settings and images, but no masks. Work notes appear on the board and are not included in generation prompts.

Choose the image generation model in detailed settings. SD Turbo is for quick drafts. SDXL does not guarantee precise details, colors, or consistency between candidates. English descriptions are recommended. GPU work that has already started may continue after cancellation.
