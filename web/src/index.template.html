캐릭터 작업실 사용 안내

  1. 용도·소개·외형을 입력하세요.

    예시 넣기로 시작할 수도 있습니다. 용도는 디자인 지시를 바꾸며 생성 모델을 바꾸지는 않습니다.

  2. 후보를 만들고 비교하세요.

    한 번에 1–2개를 탐색합니다. 오른쪽 후보에서 크게 보기, 비교 선택, 이어서 수정을 이용하세요.

  3. 필요한 부분만 수정하세요.

    원본을 불러와 브러시로 수정할 곳을 칠하세요. 키보드로는 마스크 파일을 불러올 수 있습니다.

  4. 프로젝트와 보드를 저장하세요.

    프로젝트 파일에는 설정과 이미지가 포함됩니다. 마스크는 포함되지 않습니다. 작업 노트는 보드에 담기며 생성 문장에는 사용되지 않습니다.

현재 SD Turbo는 디자인 방향 탐색용입니다. 영어 설명을 권장하며 세부 특징·색상·후보 사이의 일관성은 보장되지 않습니다. 취소 후에도 이미 시작한 GPU 연산은 계속될 수 있습니다.
