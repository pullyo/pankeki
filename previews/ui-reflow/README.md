# 중단 시점의 UI 작업본

2026-10-20 사용자의 작업 중단 지시에 따라 저장한 미완성 디자인입니다.
기본 `web/` 검수본과 분리했습니다. 최신 방향은 유리 효과를 제거한 불투명한 아이보리 화면입니다.

큰 캔버스 중심 재배치를 작성했으나, 최종 브라우저 QA·실제 부위 썸네일·타임라인 연결·다른 화면 통일은 미완료입니다. 완료된 서비스 화면으로 소개하지 않습니다.

저장소 루트에서 빌드 후 별도의 로컬 정적 미리보기로 확인할 수 있습니다.

```powershell
py -3.12 previews/ui-reflow/web/build.py
py -3.12 -m http.server 8198 --bind 127.0.0.1 --directory previews/ui-reflow/web
```

정적 미리보기는 ComfyUI 이미지 생성이나 Codex 연결을 제공하지 않습니다. 기본 앱의 동작 및 수용 검증 결과를 이 작업본에 적용하지 않습니다.
